HERDR HUD — macOS 1.2
Ubuntu 1.2 terminal interaction update: plain-text drag selection and history,
clipboard text paste, browser links, paired CLI colors, focus, and VS Code Dark.

REQUIREMENTS
• Apple silicon Mac (M1 or later), macOS 27 or later.
• Herdr installed separately. This app was developed with Herdr 0.9.1.
  Installation instructions: https://herdr.dev/docs/install/
• Intel Macs and older macOS versions are not supported by this build.

INSTALL
1. Open the DMG and drag Herdr Hud into Applications.
2. Eject the DMG, then open Herdr Hud from Applications.
3. If Herdr is not found, open the gear button → Herdr connection → Browse…,
   select your Herdr executable, then click Retry. Automatic discovery checks
   ~/.local/bin/herdr and PATH.

FIRST LAUNCH
This app uses an ad-hoc signature and is not Apple notarized. macOS may block it after it is downloaded or shared.
If you trust the GitHub download, first try opening it, then use
System Settings → Privacy & Security → Open Anyway, and confirm Open.
Apple's instructions: https://support.apple.com/en-us/102445

USE
• Click the floating H to show or hide Hud; drag H to move it.
• Use + New space and the + next to a space to add terminals.
• Drag normally to select/copy; Shift+click/drag controls interactive CLIs.
• Drag past an edge to extend history selection; release then type normally.
• Command/Control-click web links to open the browser. Right-click or
  Command/Control-V pastes text; image-only paste retains the CLI shortcut.
• Fresh preferences use VS Code Dark. Existing theme choices are preserved.
• The gear opens Settings. Choose theme… offers theme previews and Light/Dark.
• Closing/hiding Hud keeps sessions running. Quitting disconnects only Hud's
  display clients; it does not stop Herdr servers, terminals, or agents.
• Explicit Close on a terminal or space does stop that terminal or space.
